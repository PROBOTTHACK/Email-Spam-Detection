# 📧 Email Spam Detection using SVM

This project is a machine learning-based Email Spam Detection system built using a Support Vector Machine (SVM) classifier. The model is trained on a labeled dataset of emails and achieves **99% accuracy** in classifying messages as spam or not spam. The project demonstrates the power of classical ML models with effective preprocessing and feature extraction techniques.

## 🚀 Project Overview

Spam emails are not only annoying but can also pose security risks. This project aims to build a reliable spam detector using:

- **Support Vector Machine (SVM)** for classification
- **TF-IDF Vectorization** for feature extraction
- **Pandas** and **NumPy** for data manipulation
- **Scikit-learn** for modeling and evaluation

## 📌 Instructions to Run the Project on Google Colab

1. **Open Google Colab**  
   Go to [Google Colab](https://colab.research.google.com/) and open the provided notebook or upload your own `.ipynb` file.

2. **Upload the Dataset**  
   - Click on the **folder icon** on the left sidebar in Colab.
   - Click on the **upload icon** and upload the `emails.csv` file.

3. **Run the Notebook**  
   - Go through the notebook cell by cell.
   - Execute each block in order by pressing `Shift + Enter`.

4. **View Results**  
   - After training, the notebook will display the accuracy, confusion matrix, and classification report.
   - The SVM model is expected to achieve **around 99% accuracy**.
